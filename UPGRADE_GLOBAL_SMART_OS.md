# Eye of Chaos / VoidOS — Global Smart OS Experimental Upgrade

This is an experimental continuation of `eye_of_chaos_voidos_v2_0_0`. Keep the original archive untouched.

## New in this build
- **Void Arcade / Rift Runner**: original playable Canvas game, keyboard and touch controls, score/levels, and local high score.
- **Void Store**: Rift Runner is listed as a playable built-in game. The store button opens its local app page rather than pretending to download an APK.
- **CHAOS Terminal**: quick command buttons, opt-in local text-example collection, synthetic sound, local corpus/lexicon statistics, and JSON export of available CHAOS memory keys.
- **VoidBrowserX**: expanded developer-site shortcuts and shortcuts to built-in VoidOS apps. Websites that block iframe embedding still need the external-browser action.
- **`settings.html` is the Settings app**: added settings backup/restore, local-storage diagnostics, and clearing known local browser-history keys.
- The modified root pages and app files are mirrored under `cordova-project/www`.

## Quick test
1. Extract to a new folder.
2. Open `eye_of_chaos/eye_of_chaos_site/index.html`.
3. Launch Void Arcade from the home screen, then from Void Store.
4. Open Terminal and test command chips, local training (with your own sample), sound, stats, and export.
5. Open `settings.html` and test export/import on a small backup file.
6. Open VoidBrowserX and test local shortcuts and external websites.

## Honest limitations
- The text engine is a small local Markov-style text generator, **not** a neural large language model; adding examples does not train neural-network weights.
- Local accounts and settings are browser/device-local, not cloud identities or cross-device sync.
- Synthetic audio is generated by Web Audio; it is not a recorded human voice or full speech synthesis.
- The browser cannot bypass website iframe restrictions.
- Native Android services and a signed APK have not been built or verified by this archive update.
