PROJECT RULES
- This is an experimental web-first operating-system-like environment, not a replacement Android kernel.
- The historical stable mother baseline is eye_of_chaos_voidos_v3_0_0. This release candidate is a later experimental development branch; keep the original archive unchanged. This v3.1.6 release candidate continues the v3.1.5 experimental branch and includes the OS-runtime and per-application modularization work described in README/V3_1_6_OS_EVOLUTION.txt.
- No APK is claimed to have been built, installed, or tested on a physical device by this package update.
- Cloud AI and synchronization remain opt-in and disabled unless deliberately configured.
- Do not place API secrets in client-side JavaScript.


Experimental v3.1.1 cosmic audio identity is documented in CHANGELOG_v3_1_1_COSMIC_PRESENCE_EXPERIMENTAL.md and README/04_VOICE_FOUNDRY.txt. It is procedural, offline, and activated only by user controls or explicit CHAOSAI custom events.
