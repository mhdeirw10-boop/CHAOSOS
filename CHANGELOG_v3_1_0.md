# CHAOSOS v3.1.0 — Local Runtime, Hybrid Language & Procedural Voice (Experimental)

- Added `js/kernel/runtimeOrchestrator.js`, a local-first capability-aware service facade with inventory, health checks, and confirmed mutation boundaries.
- Added `js/brain/cognition/localLanguageRuntime.js`: bounded local intent handling, knowledge retrieval, safe arithmetic, ephemeral current-page context, and separately labelled statistical generation.
- Integrated grounded local responses into terminal execution before the legacy fallback.
- Rebuilt the procedural voice engine with multiple synthesized layers, adjustable machine/radio/deep timbre, synthetic noise bursts, and no required downloaded audio.
- Improved Void Game Manager with favorites, sorting, network-reference rejection for imported standalone HTML, and a restrictive sandbox CSP.
- Consolidated every README* document into the English-only `README/` directory with paths and component descriptions.
- Bumped the experimental version and offline cache namespace.
- No APK build, physical device test, external server deployment, or independent neural LLM is claimed. The canonical v2.0.0 baseline remains untouched.
