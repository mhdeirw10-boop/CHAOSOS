# Eye of Chaos VoidOS v2.1.0 — Phone Foundation Experimental

## الهدف
تجهيز أكبر قدر من الأساس البرمجي الذي يمكن تطويره والتحقق منه من الهاتف قبل تأجيل المهام الثقيلة إلى كمبيوتر Windows. هذه نسخة تجارب مستقلة مبنية على `eye_of_chaos_voidos_v2_0_0_chaosai_browser_apps_accounts_experimental.zip`؛ لا تستبدل الأرشيف الأصلي.

## إضافات هذا الإصدار
- ترقية طبقة `VoidOS` المحلية إلى API ذات رقم إصدار واضح `2.1.0`.
- تحسين اختيار أصوات TTS: مطابقة اللغة، كشف توفر أصوات العربية، حدود للسرعة/النبرة/الصوت، ورسائل خطأ منظمة بدل الإيحاء بأن الصوت يعمل دائمًا.
- إضافة `availableVoices()`, `voiceStatus()`, و`foundationStatus()` لفحص البيئة.
- إضافة تصدير/استيراد نسخة JSON احتياطية لمفاتيح `voidos_*`, `voidStore*`, و`chaos_*` مع فحص الشكل وحدود للحجم، وتحذير واجهة قبل الاستيراد.
- إضافة صفحة `diagnostics.html` لفحص البيئة وتجربة النطق والنسخ الاحتياطي.
- تحديث ملفات Cordova المرآتية ونسخة `package.json` و`config.xml` إلى 2.1.0 حيث أمكن.

## حدود صريحة
- ما يزال هذا مشروع ويب/Cordova وليس نظام Android مستقلًا.
- لا يوجد خادم حسابات أو مصادقة موحدة بين الأجهزة. الهوية والتخزين محليان.
- TTS يعتمد على محرك WebView/Android والأصوات المثبتة؛ لا يمكن للكود وحده تثبيت صوت عربي أو ضمان جودة الصوت.
- متصفح VoidBrowserX لا يزال يستخدم تقنيات عرض الويب المتاحة؛ لم يُبنَ محرك Chromium مستقل.
- لم تُبنَ APK ولم يُختبر هذا الإصدار على الهاتف الفعلي ضمن هذه العملية.

## اختبار سريع
1. فك ضغط ZIP كاملًا.
2. افتح `eye_of_chaos/eye_of_chaos_site/diagnostics.html` من نفس بيئة تشغيل المشروع.
3. افحص حالة البيئة، جرّب النطق العربي، ثم صدّر نسخة احتياطية.
4. لا تختبر الاستيراد على بياناتك الوحيدة؛ احتفظ بنسخة إضافية أولًا.
5. عند توفر بيئة Node، شغّل الاختبارات الموجودة في `tests/`، ثم نفّذ بناء Cordova على جهاز التطوير.

## ما أُجّل إلى Windows
- بناء APK واختباره على جهاز فعلي ومحاكي مع سجلات Logcat.
- غلاف Android أصلي/محرك متصفح أقوى وتكاملات نظام حقيقية.
- تصميم خادم هوية ومزامنة آمنة، وخدمات API للمتجر والفيديو.
- اختبارات أمنية وأداء واسعة.
