# CHAOSOS v3.0.0 — Adaptive Intelligence & Voice Foundry (Experimental)

- يوحّد مسار الوكيل التكيفي بخطة محدودة وخطوات قابلة للفحص، مع تقييمات صريحة لا تحفظ نصوص المهام.
- يضيف مصنع صوت محليًا يولّد نغمات فورمانتي من النص عبر Web Audio، ووضعًا اختياريًا لمحرك النطق المدمج بالجهاز.
- يزيل الفقاعات النصية الدائمة ويستبدلها بمؤشر سياقي صغير بلا اسم ظاهر؛ لوحة المساعدة لا تظهر إلا بطلب المستخدم.
- يضيف Void Game Manager لمكتبة ألعاب الويب المسجلة واستيراد ملفات HTML مستقلة إلى IndexedDB وتسجيل وقت اللعب.
- يجهّز تكاملات المستقبل مع النموذج السحابي والطبقة الأصلية دون تفعيل السحابة أو التحكم الحقيقي في Android.
- لا APK مبني، ولا خادم منشور. الأصل `eye_of_chaos_voidos_v2_0_0.zip` محفوظ كما هو.
