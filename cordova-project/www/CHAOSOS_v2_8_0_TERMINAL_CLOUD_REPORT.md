# CHAOSOS v2.8.0 — Terminal and Cloud Operations (Experimental)

هذه نسخة تجريبية مبنية على v2.7.0. بقي الأصل `eye_of_chaos_voidos_v2_0_0.zip` دون تعديل.

## ما تغير
- `terminal.html` أصبح مدخل تحويل خفيفًا إلى `terminal/index.html`، من دون تحميل سكربتات في صفحة ستغادر فورًا.
- إضافة `js/terminal/terminalCloudConsole.js` ولوحة حالة/إعداد/فحص للخادم داخل واجهة الطرفية.
- تحميل `cloudAdapter.js` و`aiGateway.js` صراحةً في الطرفية بدل الاعتماد على تحميل غير مضمون.
- ضبط مهلة الاتصال ضمن 1–30 ثانية، وتثبيت بادئة API على `/api/v1` وعدم إظهار أي أسرار عميل.
- مزامنة التعديلات مع نسخة Cordova تحت `cordova-project/www/`.

## السحابة والأمان
السحابة متوقفة افتراضيًا. تفعيل الاتصال يتطلب تأكيدًا وعنوان HTTPS صالحًا؛ HTTP العام مرفوض. زر فحص الصحة لا يرسل المحادثة. بوابة الذكاء الاصطناعي تبقى مستقلة وتتطلب موافقة لكل طلب ورمز جلسة، ومفاتيح مزود الذكاء الاصطناعي تبقى على الخادم. لا تنشر الخادم من هذه الحزمة ولا تستخدمها مع بيانات حساسة قبل إضافة مصادقة حقيقية وقاعدة بيانات دائمة واختبارات أمنية مستقلة.

## التحقق
اختبارات ساكنة ووظيفية خاصة بمدخل الطرفية والتحميل والتكوين؛ لا تعني اختبار WebView مرئيًا أو بناء APK أو جاهزية إنتاجية. بناء APK مؤجل إلى الحاسوب.
