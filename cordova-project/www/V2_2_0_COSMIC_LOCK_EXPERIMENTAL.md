# v2.2.0 Experimental Branch

Parent: `eye_of_chaos_voidos_v2_1_1_phone_foundation_plus_experimental.zip`
Canonical baseline remains unchanged: `eye_of_chaos_voidos_v2_0_0.zip`.

This branch adds a cosmic lock screen and optional PIN entry, plus a quick-settings entry to configure the lock. It retains the existing simulated quick toggles and recent-apps overlay. The PIN is hashed when Web Crypto is available; compatibility fallback is not cryptographically secure. This feature is for interface flow only and must not be described as Android-level security.
